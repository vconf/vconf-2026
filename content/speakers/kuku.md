新版本發布後，我們總是在討論新增了哪些功能；但真正重要的是，它是否改善了專案裡每天都會遇到的問題。

本次分享將透過一系列可重複驗證的實驗，檢視 Vue 3.6 在真實 Runtime 場景中的表現，並整理實驗結果與工程觀察，而不是只看 Release Notes。

同時，也會分享 AI Coding 導入團隊後，如何建立 Prompt、Design System 與 Code Review 規範，讓 AI 成為提升品質的助力，而不是技術債的加速器。

希望大家帶走一套能驗證框架演進、也能應對 AI Coding 時代的 Vue 工程實踐。
