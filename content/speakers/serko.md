Vue Language Tools 是一個跟 Vue 有關的 Language Tools。平時我們在寫 Vue 的時候，可能有用過，也可能沒有特別留意自己有沒有用過，但不管有沒有留意，這次主要就是想簡單介紹一下 Vue Language Tools。

會先從 Vue Language Tools 開始，看看 Vue Language Tools 到底是甚麼，然後再看看裡面有甚麼。知道裡面有甚麼之後，我們就可以再看看這些東西為甚麼會在裡面，以及它們在裡面做甚麼。有些東西可能比較容易理解，有些東西可能要先理解另外一些東西，才能理解原本想理解的東西。不過沒有關係，我們會從比較前面的地方開始。

過程中也會稍微看看，當我們平時做一些很普通的事情時，Vue Language Tools 做了一些甚麼。

如果以前沒有接觸過 Vue Language Tools，也沒有問題。因為既然是新手入門，自然會從新手可以入門的地方開始。至於入門之後會去到哪裡，就要入門之後才知道。

總之，這是一個 Vue Language Tools 的新手入門，應該不會有甚麼特別的。
